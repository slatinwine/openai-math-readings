# 解读 | Integer multiplication below n log n

> 结果族 109：Integer multiplication below `@@M@@n\log n@@`　·　学科：Theoretical computer science　·　验证状态：暂无形式化证明，请以社区核验为准

## 一句话结论

本文构造了一台固定字母表、固定带数的多带图灵机，对所有输入长度精确计算两个 `@@M@@n@@` 位整数的乘积，最坏时间 `@@M@@O(n(\lg n)^{1-2^{-182}})@@`：在普通多带比特模型中严格跌破 `@@M@@n\log n@@`，推翻了 Schönhage–Strassen 的最优性猜想。

## 问题背景

1971 年，Schönhage 与 Strassen 在多带图灵机（multitape Turing machine）上给出 `@@M@@O(n\log n\log\log n)@@` 的整数乘法，并猜想 `@@M@@n\log n@@` 是该模型的最优增长阶。经过近半个世纪的一系列改进，Harvey 与 van der Hoeven 于 2021 年达到无条件的 `@@M@@O(n\log n)@@` 上界，恰好停在猜想阈值上，而任何非平凡下界始终无从建立。卡点在于比特模型中"搬运数据就是代价"：卷积需要 `@@M@@\Theta(\log n)@@` 层变换，每层似乎又必须扫过 `@@M@@\Theta(n)@@` 个存储比特，合计天然是 `@@M@@\Theta(n\log n)@@`。要想严格更快，必须在数据搬运与算术运算两个维度同时省下对数因子中的幂。

## 主要结果

主定理：存在一台确定性图灵机 `@@M@@A@@`，字母表与一维带条数均为固定有限，对每个 `@@M@@n\ge 1@@` 和每对 `@@M@@n@@` 位输入都输出精确的 `@@M@@2n@@` 位乘积，最坏时间为 `@@M@@T_A(n)=O(n(\lg n)^{1-\kappa})@@`，其中 `@@M@@\kappa=2^{-182}@@`。指数上的节省极其微小，却是严格的幂节省（power saving），因而反驳了该模型中任何固定乘法机器可能有的 `@@M@@\Omega(n\log n)@@` 下界。作者明言构造中的常数与阈值极大，目的是建立比特复杂度（bit complexity）纪录，而非实用算法。同文推论还给出同样时间的精确除法（输出商与余数）与整数平方根，由 Brent 式 Newton 迭代归约到乘法。

## 证明思路

起点是 Harvey–van der Hoeven 的高斯重采样（Gaussian resampling）归约：先把乘法化作轴长全为 2 的幂的多维变换，再把最后一维装进多项式环 `@@M@@\mathbb C[y]/(y^r+1)@@`（`@@M@@r@@` 为 2 的幂），使"乘单位根"退化为系数表的带符号移位（Nussbaumer 合成多项式变换）。此后整个变换只剩地址重排、带符号移位与两点蝶形（butterfly）；但逐层全量扫描仍是 `@@M@@\Theta(n\log n)@@`，节省必须同时来自搬运与算术。

核心新工具是一个固定线性网络：`@@M@@W@@` 条线加上各自的暂存线，能把两组标量带符号互换并还原全部辅助值（恢复任意初值的技巧是 Buhrman 等人"透明计算"构造的线性版本）。把数组的行循环分配到 `@@M@@W@@` 个角色（role）流，并在源、门、汇处指定可逆线性框架（frame）`@@M@@D_v@@`；因为公共框架与逐点线性门可交换，中间框架沿路径层层抵消，端点只剩想要的算子——位网络得到地址剪切 `@@M@@(H,D)\mapsto(H+D,D)@@`，复数网络得到同时作用的蝶形层 `@@M@@H_0(u,v)=((u+v)/2,(u-v)/2)@@`。框架标注用 `@@M@@h=100@@` 元集合的三元子集及其正交子空间实现（Alon 式组合构造）；决定性计数是：每条边的框架变化都能由更小的同类调用实现，而递归调用总数 `@@M@@s<Wm@@`（`@@M@@m=h^3=10^6@@`）。于是参数放大 `@@M@@m@@` 倍的一次调用只花 `@@M@@s@@` 次体积 `@@M@@V/W@@` 的小调用，`@@M@@s/W<m@@` 这一严格不等式沿递归几何级数放大，得到地址块交换 `@@M@@O(Vu^{\tau})@@` 与同时蝶形层 `@@M@@O(Vd^{\lambda'})@@`，其中 `@@M@@\tau=1-2^{-50}@@`、`@@M@@\lambda'=1-2^{-54}@@` 均固定小于 1。

最后是总装：先用 Agarwal–Cooley 式中国剩余映射把一维循环卷积分到互素素数长度的轴上，实现为三角受控循环移位而非整体排序；高斯重采样恒等式刻意保留源与目标坐标置换，使其在两正一反三次变换中相消、无需单独执行排序；Bluestein 啁啾（chirp）恒等式把中间变换化为循环卷积，相位扭转转入环 `@@M@@\mathbb C[y]/(y^r+1)@@`，其中的多项式乘法把已知的 `@@M@@O(n\log n)@@` 乘法器当普通子程序调用。取工作精度 `@@M@@p=6\lceil\log_2 n\rceil@@`，逐级舍入误差分析给出最终系数误差 `@@M@@448b\,2^{-3b/4}<1/2@@`（`@@M@@b=\lceil\log_2 n\rceil@@`），四舍五入恢复整数系数、传播进位即得精确 `@@M@@2n@@` 位输出。代价表七个主导项的指数余量最小为 `@@M@@2^{-181}=2\kappa@@`，足以吸收零散对数因子，合计 `@@M@@O(n(\lg n)^{1-\kappa})@@`。
