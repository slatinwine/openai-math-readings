## 入门导读 🐣

上一篇说"再调皮的形状，`@@M@@n\log n@@` 层也准能铺满"；这篇反着来：真的存在特别难伺候的凸体——哪怕允许任意平移、任意稀密的摆法，平均层数也压不到 `@@M@@c\,n\log n@@` 以下。两篇合起来，高维覆盖问题的"难度标尺"被精确刻上了度。

**关键词卡片**

- 平移覆盖密度（translative covering density）：只用平移副本铺满空间所需的最小平均重叠层数。
- 中心对称（central symmetry）：形状关于原点镜像对称。
- 平板（slab）：两张平行超平面之间的"条带"，高维空间的切割刀。
- 泊松过程（Poisson process）：随机撒点的标准概率模型，这里用来随机抽切割方向。
- 见证点（witness）：落在所有副本之外的"洞"，一票否决一个覆盖方案。

**看个具体例子**

公式卡（数字版定理）：随机取一个半径略大的球，与一族随机方向平板的交作为凸体 `@@M@@K_n@@`（还可以取成有理顶点的对称多胞形）。定理说：存在绝对常数 `@@M@@c>0@@`，当 `@@M@@n=10^6@@` 时可造出 `@@M@@K_n@@` 使得
`@@M@@D\theta_T(K_n)>c\cdot n\log n\ \approx\ c\times 1.38\times 10^7 ,@@`
任何平移覆盖都别想更省。与之相对，Rogers 的经典上界是 `@@M@@n\log n+n\log\log n+5n@@`——阶数严丝合缝，最终答案是 `@@M@@\Theta(n\log n)@@`。诀窍是"见证点"：随机平板几乎必然在每个候选点附近切出一块所有副本都够不着的地方，留下没盖住的洞，一票否决该覆盖方案。

**为什么值得关心**

它否定"存在常数 `@@M@@C@@` 使一切凸体都只需 `@@M@@Cn@@` 层"的线性猜想（Naszódi 问题），且是在"最坏体可任选"的最强意义下否定；配合姊妹篇，四个覆盖密度量的阶全部锁定。

## 由浅入深：从类比走向定理

**第一级台阶**

导读说这篇要"反着来"：不再问怎么铺最省，而是造出一个特别难伺候的形状——无论把它的副本怎么平移、摆得或稀或密，平均每点被压住的层数都压不到某个常数乘 n·log n 以下。造法是随机切割：拿一个略放大的球，用一大批随机方向的平板去削，削剩下的凸块就是候选的"刺头"。判它赢的手段是见证点——只要随机切割在每个候选点附近都留下一块所有副本都够不着的死角，这个覆盖方案就被一票否决。

**第二级台阶**

术语化：平移覆盖密度定义为体积乘以中心集合的上渐近密度再取下确界，中心集只要求局部有限，甚至无须渐近密度存在；经典周期化原理说明它等于允许任意多个格陪集的周期覆盖密度。切割方向由球面上的泊松过程采样；每个副本在目标点处"够不着"对应法向球面上的一对帽，帽被泊松点命中即产出洞。

**第三级台阶**

定理断言：存在绝对常数与维数阈值，使每个充分大的维数中都有一个中心对称凸体——甚至可取有理顶点的多胞形——其平移覆盖密度超过 c·n·log n。"体可任选"是最强意义下的反例：它否定了一切凸体共享线性上界的猜想，与 Rogers 的 n·log n 上界相配，把最坏覆盖密度的阶钉在 Θ(n log n)。随机切割须以正概率保住体积下界，见证论证须对所有可能的覆盖模式一致成立，两条概率底线缺一不可。

## 一句话结论

在充分大的每个维度构造出中心对称凸体，其任意平移覆盖的密度都超过 `@@M@@cn\log n@@`，否定了一致线性上界猜想；与 Rogers 上界相配，最坏平移覆盖密度的阶被钉在 `@@M@@\Theta(n\log n)@@`。

## 问题背景

平移覆盖密度 (translative covering density) `@@M@@\theta_T(K)@@` 度量用凸体 `@@M@@K@@` 的副本铺满 `@@M@@\mathbb{R}^n@@` 所需的最小平均重叠，覆盖中心集合只要求局部有限 (locally finite)，甚至不需要存在渐近密度。Rogers 1957 年证明每个凸体都有密度至多 `@@M@@n\log n+n\log\log n+5n@@` 的周期平移覆盖，Fejes Tóth 后来用 `@@M@@O(\log n)@@` 个陪集达到同阶。下界一侧，Coxeter–Few–Rogers 对等球覆盖给出 `@@M@@\Omega(n)@@` 的障碍，球的精确阶至今悬而未决。Naszódi 记录的问题问：是否存在绝对常数 `@@M@@C@@`，使一切维度、一切凸体都有 `@@M@@\theta_T(K)\le Cn@@`？本文给出否定回答，而且是在"最坏的体可任选"这一最强意义下。

## 主要结果

主定理：存在绝对常数 `@@M@@c>0@@` 与 `@@M@@n_0@@`，对每个整数 `@@M@@n\ge n_0@@`，存在中心对称凸体 `@@M@@K_n\subset\mathbb{R}^n@@` 使

`@@M@@D\theta_T(K_n)>c\,n\log n.@@`

体还可以取为具有有理顶点的中心对称多胞形 (polytope)。结合 Rogers 的经典上界与姊妹篇的单格上界定理，四个量——一般或中心对称凸体、平移或格点覆盖——的密度上确界阶均为 `@@M@@n\log n@@`。

## 证明思路

随机构造：取半径 `@@M@@b=a(1+1/n)@@` 的球与一族对称平板 (slab) 之交

`@@M@@DK=bB\cap\bigcap_{u\in\Pi}\{x:|u\cdot x|\le1\},@@`

法向 `@@M@@u@@` 由球面 `@@M@@S^{n-1}@@` 上强度 `@@M@@\mu=M\sigma@@` 的泊松过程 (Poisson process) `@@M@@\Pi@@` 采样。先证以正概率 `@@M@@|K|>2v\omega_na^n@@`：球 `@@M@@aB@@` 内任一点被切掉的法向测度至多为 1，故期望保留体积至少 `@@M@@e^{-1}@@` 倍，再用上下界夹出严格体积事件。

反证设存在中心强度 `@@M@@\le\rho_0=R/(2v\omega_na^n)@@` 的周期覆盖。关键新机制是决定性局部化：对带重复指标的中心多重集用周期平均恒等式（Tonelli 论证），找到一个平移窗口，其中保留中心数不超过 `@@M@@N_n@@`，且至少一半的点满足"没有中心过近、相关残差个数与径向权重都有预算"；把中心舍入到固定网格，得到覆盖小窗 `@@M@@B_D@@` 的有限列表 `@@M@@P@@`。所有可能列表构成在体采样之前就固定的有限类 `@@M@@\mathcal F_n@@`，其熵不超过 `@@M@@\exp(\lambda_0n+O(\log n))@@`。这样，即使格与陪集是在体选定之后才挑的，也逃不出这个类。

固定 `@@M@@P@@`，证它极难覆盖 `@@M@@B_D@@`：目标 `@@M@@y@@` 处只有距离 `@@M@@\le b+3\eta@@` 的中心相关，残差 `@@M@@x_i=y-p_i@@` 决定球面切割帽 `@@M@@C_i=\{u:|u\cdot x_i|>1+3\eta\}@@`——只要泊松过程在每个相关帽内各落一点，`@@M@@y@@` 就是洞。为处理近重合切割事件的强相依，仿 Li–Liu 把帽分块、每块取一个公共法向子集，把"每个帽被命中"化为"每个槽位分到互异泊松点"的注入计数 `@@M@@Z_y@@`。核心工具是连续版 Janson 下尾不等式：先证允许重复指标的有限 Bernoulli 版本（Harris 相关不等式加私有 Bernoulli 技巧），再用胞腔剖分逼近可测槽位，得 `@@M@@\Prob\{Z_y=0\ \forall y\}\le\exp[-(\sum\nu_y)^2/(2\sum D_{yz})]@@`，协方差项 `@@M@@D_{yz}@@` 由部分匹配图 (partial matching diagram) 控制。目标选取用圆柱体积估计在两个角度尺度上分离：任意目标对的残差方向都分开 `@@M@@H\sqrt{\log n/n}@@`（保证交叉图 `@@M@@\le n^{-3}\nu_y\nu_z@@`），除 `@@M@@\exp(-\gamma n)@@` 比例外都分开 `@@M@@4\sqrt\varepsilon@@`（交叉图为零）；把 `@@M@@e^{n\log n/16}@@` 个目标按活跃度 `@@M@@\nu_y@@` 分箱，同箱目标让分子的平方压倒自重叠 `@@M@@e^{C_*R}@@`，得到双指数小的覆盖概率。最后对所有 `@@M@@P\in\mathcal F_n@@` 取并：因 `@@M@@\gamma>\lambda_0@@`，总失败概率 `@@M@@o(1)@@`，故存在实现同时满足体积下界且无任何保留模式覆盖 `@@M@@B_D@@`，于是 `@@M@@\theta_T=\theta_{\mathrm{per}}\ge\rho_0|K|>R@@`，其中周期化等价 `@@M@@\theta_T=\theta_{\mathrm{per}}@@` 在附录证明。

## 可信度与备注

本文暂无形式化证明。证明建立在 Li–Liu 格点下界的随机平板与泊松见证方法之上，新增的局部化论证专门排除任意有限个格陪集的中心构型；姊妹篇的单格上界与本文下界共同把四个密度量的阶定为 `@@M@@n\log n@@`。按 OpenAI 官方声明，未经形式化的结果可能有问题，请以社区核验为准。

## 深入探讨：像审稿人一样追问 🔍

**问 1：证明中最脆弱的一环是什么？**

答：两处。一是连续版 Janson 下尾不等式——论文须自证有限 Bernoulli 版本（Harris 相关加私有 Bernoulli 技巧）再经胞腔剖分逼近可测槽位，其协方差项靠部分匹配图控制，依赖刻画最细的估计链；二是"体采样之前就固定"的有限模式类：其熵 exp(λ₀n+O(log n)) 必须被双指数小的覆盖失败概率压倒，γ>λ₀ 的余量一旦算错，对所有模式取并的论证整体塌方。论文明言二阶矩方法给不出所需衰减。

**问 2：Li–Liu 已有格点下界，为什么平移下界不是自动的？**

答：格点下界只排除"中心构成单个格"的覆盖；平移覆盖允许任意多个格陪集乃至完全非周期的中心集。格基网格无法编码任意数目的陪集，本文新造决定性局部化：用周期平均恒等式在固定窗口内截获带重数的中心列表、舍入到有限网格，得到先于体采样固定的有限类，从而连"看过体再挑摆法"的对手也被一并排除。

**问 3：与 Bukh 等人的随机中心障碍相比，新意何在？**

答：Bukh–Gao–Liu–Pikhurko–Sun 证明随机中心在 n log n 密度下大概率盖不住给定体，但量词不同——某个例外安排仍可能高效覆盖。本文反过来让体随机、结论对一次实现同时排除所有周期安排，是"最坏体"意义下的严格下界。

**问 4：为什么只对充分大的维数、且允许每个维数挑一个体？**

答：证明需要 exp(c₁n log n) 个目标点去吸收自重叠代价 exp(CR)，以及两类角度尺度的分离估计，这些都只在 n 大时闭合；常数 c 亦未优化。至于"体可任选"：球的覆盖密度至今只有 Ω(n)（Coxeter–Few–Rogers）与 (1/2+o(1))n log n（Dumer）的上界，缺口仍在，本文锁定的是凸体族上确界的阶。

**问 5：中心对称是限制还是加强？**

答：是加强。定理造出的难伺候体本身就是中心对称的，甚至可取有理顶点的对称多胞形，说明即便在最规矩的体中线性上界也不存在——比只造非对称反例更强。

**问 6：这篇论文最可能以什么方式出错？**

答：AI 生成证明的典型风险在此集中于概率组合的细节：双角度尺度的圆柱体积估计若在指数小例外比例上失准、帽分块与注入计数的相依结构刻画不全、或周期化等价（附录）在非周期安排上下密度不相等时处理有漏，结论都会动摇。本文未形式化，应以社区核验为准。

**问 7：谁会用到它？**

答：与姊妹篇单格上界合璧后，一般/对称凸体在平移/格点四种意义下的最坏覆盖密度阶全部锁死，覆盖纲领的收官陈述由此成立；连续 Janson 不等式与"先固定模式类再取并"的局部化技术对其他随机几何排除问题有独立引用价值。

**总评**

这是把 Rogers 上界配上匹配下界、从而终结最坏覆盖密度阶问题的下半场，证明组合精巧、量词处理干净；最大风险是它未经形式化且重概率细节，Janson 下尾与熵并列抵消两处余量最需独立复核。
