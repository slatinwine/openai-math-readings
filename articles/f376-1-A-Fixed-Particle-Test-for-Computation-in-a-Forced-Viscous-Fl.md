# 解读 | A Fixed Particle Test for Computation in a Forced Viscous Flow

> 结果族 376：Universal computation in forced Navier–Stokes flows　·　学科：Partial differential equations　·　验证状态：暂无形式化证明，请以社区核验为准

## 入门导读 🐣

同一杯"会算数的水"，这篇换了个更豪爽的做法：直接使用图灵机的原装指令，哪怕指令会覆盖旧数据。被擦掉的历史去哪了？写进第三个空间坐标的小数展开里——像一本越写越长的账本，每新增一位就记下"刚才执行了第几条指令"，旧账永不抹去。

**关键词卡片**

- 图灵机（Turing machine）：纸带＋读写头＋有限指令表的最通用计算模型。
- 历史编码（history encoding）：第 n 步所选指令的编号 jₙ 逐位写进第三坐标 z 的 Λ 进制小数。
- 周期门（periodic gate）：按 z 的当前小数位挑选指令的开关，更早的数位自动"翻篇"失效。
- 混合导数（mixed derivatives）：对时间与空间反复求导；本文让它们全部既有界又平方可积。
- 平方可积（square-integrable）：平方后可积，物理上常对应有限能量一类的正则性。

**看个具体例子**

设共有 J 条指令，取 Λ=J+1。若第一步选了第 3 条、第二步选了第 5 条，第三坐标就是 z=0.35…（Λ 进制）。想读出第 n 步？用这张"数字版定理"：

`@@M@@z=0.j_1j_2j_3\cdots_{(\Lambda)}\quad\Longrightarrow\quad \Lambda^{n}z \equiv j_n/\Lambda \ (\mathrm{mod}\ 1)@@`

小数点后第 n 位自动冒到最前，选出正确指令；旧数位化作整数部分，不再干扰。为压制门函数高阶导数付出的 Λⁿ 因子，把第 n 步时长放大到 `@@M@@S_n=2^{n^2}@@`，误差级数 `@@M@@\sum_n 2^{-(1+2h)n^2}\Lambda^{2n\mu_z}@@` 收敛，一切导数乖乖听话。

**为什么值得关心**

它表明即使在最严格的正则性标准下（一切混合导数有界且平方可积），流体里仍藏着不可判定的计算；而且观测只需盯住一个固定颗粒与一个固定开集，几何、粘度全部事先定死，只有外力的有限程序随机器变化。

## 由浅入深：从类比走向定理

**第一级台阶**

导读把这篇的做法比作"直接用图灵机原装指令，把被擦掉的历史记进第三坐标这本越写越长的账本"。换成半数学语言：对象仍是从静止出发、装在固定环面里的一杯不可压缩黏性流体；操作是一份由机器指令表逐条翻译出来的光滑外力时刻表；两个平面坐标负责执行指令，第三个坐标负责记账——每执行一步，就往它的小数展开里添一位"刚选了第几条指令"。

**第二级台阶**

用本科术语精确化：速度场满足强迫 Navier–Stokes 方程，粘度取任意给定正数，初速为零。带头两侧的纸带各编码为一个 B 进制小数，于是每条机器指令变成一个"横缩纵伸"的仿射映射，线性部分形如对角阵 diag(λ, λ⁻¹)；不同指令的像可以重叠。第三坐标 z 以 Λ 进制记录所选指令编号：第 n 步后 Λⁿz 的首位小数恰是当前指令号，一个以 Λⁿz 为变量的周期门函数据此挑出该执行的运动。第 n 步的时长取 Sₙ=2^(n²)。

**第三级台阶**

主定理说：存在算法把任一单带图灵机与输入编译成光滑零均值外力，方程有全局光滑解且在古典类中唯一；速度与外力的一切混合导数既一致有界又在时间上平方可积——这一步靠"门函数每细一个 Λⁿ，步长就放大到平方量级"的交换；固定粒子进入固定开集当且仅当机器停机。假设各挡一种麻烦：固定正粘度与零初速排除"借几何或初速夹带程序"；历史坐标挡住光滑流必可逆与机器可抹信息之间的冲突；导数的平方可积性则挡住"门越用越细导致能量无穷"的质疑。结论还可经傅里叶投影改取无散度外力，事件不变。

## 一句话结论

在固定平坦环面、任意固定正可计算粘度、零初速的强迫 Navier–Stokes 流中，本文把普通（不可逆）图灵机直接编译为光滑外力：固定粒子进入固定开集当且仅当机器停机，且力与速度的一切混合导数在时间上既有界又平方可积，事件本身不可判定。

## 问题背景

流体中的通用计算此前需改编度规或使用非零初速；固定几何、固定粘度、从静止出发的强迫情形是空白。还有两个技术痛点：模拟图灵机的连续构造里，不同指令的平面像会重叠，这是机器不可逆性的几何体现；而保留历史的机制往往让空间门越用越细、导数估计越变越坏。本文的两项新意正是把可逆性所需的历史藏进第三个空间坐标的进制展开，并用超长的后续时间步换取所有混合导数的时间平方可积性。与同族改用可逆记录器的姊妹篇不同，这里直接使用机器的原始指令表，且粒子、探测区域、几何与粘度全部事先固定，只有力的有限程序依赖机器与输入。

## 主要结果

主定理：存在算法把确定单带图灵机 `@@M@@M@@` 与有限词 `@@M@@w@@` 编译为有效光滑零均值外力 `@@M@@f_{M,w}@@`：(1) 方程 `@@M@@\partial_tu+(u\cdot\nabla)u=-\nabla p+\nu\Delta u+f@@`、`@@M@@u(0)=0@@` 在 `@@M@@\T^3@@` 上有全局光滑解，古典类中唯一；(2) 对每个时间阶 `@@M@@h\ge0@@` 与空间多重指标 `@@M@@\mu@@`，`@@M@@\|\partial_t^h\partial_X^\mu u_{M,w}(t)\|_\infty@@` 与 `@@M@@\|\partial_t^h\partial_X^\mu f_{M,w}(t)\|_\infty@@` 都属于 `@@M@@L^\infty(0,\infty)\cap L^2(0,\infty)@@`；(3) 粒子 `@@M@@a_*=(1/8,3/8,0)@@` 进入 `@@M@@O=\{1/2<x<1\}@@` 当且仅当 `@@M@@M@@` 停机于 `@@M@@w@@`。外力还可经 Helmholtz–Leray 投影（projection）改取无散度版本，速度与观测事件不变；装载区间之后，速度机制只依赖 `@@M@@M@@` 而不依赖 `@@M@@w@@`。推论：该固定粒子事件不可判定。

## 证明思路

先做位置编码：带头两侧的带子写成 `@@M@@B@@` 进制小数 `@@M@@(\ell,r)@@`，状态方块按 `@@M@@x@@` 分层——非停机状态 `@@M@@x\le1/4@@`、停机状态 `@@M@@x\ge3/4@@`，探测带 `@@M@@O@@` 居中于 `@@M@@1/2<x<1@@`。每条指令 `@@M@@(q,l,a)@@` 化为仿射分支 `@@M@@F_j@@`，线性部分 `@@M@@\diag(\lambda_j,\lambda_j^{-1})@@`、`@@M@@\lambda_j\in\{B^{-1},B,1\}@@`；不同分支的像允许重叠。为区分重叠的历史，把已选分支的编号 `@@M@@j\in\{1,\dots,J\}@@`（记 `@@M@@\Lambda=J+1@@`）逐位记入第三坐标：`@@M@@z_n=\sum_{i<n}j_i\Lambda^{-i-1}@@`，于是 `@@M@@\Lambda^nz=j_n/\Lambda\pmod 1@@`，周期门 `@@M@@b_j(\Lambda^nz)@@` 恰好选出当前指令；旧数位化作整数部分不再影响门，却未被擦除——这是 Bennett 历史带（history tape）的连续版。执行一步用两个脉冲：先"记录"，平面坐标不动、`@@M@@z@@` 增加 `@@M@@j_n\Lambda^{-n-1}@@`；再"执行"，`@@M@@z@@` 不动、门选出对应的哈密顿场（Hamiltonian field）`@@M@@V_{j_n}@@`，粒子沿路径 `@@M@@\Psi_{j,s}@@`——中心线性插值配上互逆伸缩 `@@M@@\diag(g_j(s),g_j(s)^{-1})@@`——精确到达下一个机器码；凸性保证非停机到非停机的路径全程 `@@M@@x\le1/4@@`。最精细的一步是导数估计：对门 `@@M@@b_j(\Lambda^nz)@@` 求高阶 `@@M@@z@@` 导数需付出 `@@M@@\Lambda^{n\mu_z}@@` 的因子，于是取步长 `@@M@@S_n=2^{n^2}@@` 并在速度中放入 `@@M@@1/S_n@@`，得 `@@M@@\|\partial_t^h\partial_X^\mu U(t)\|_\infty\le C_{h,\mu}S_n^{-1-h}\Lambda^{n\mu_z}@@`；平方求和后级数 `@@M@@\sum_n2^{-(1+2h)n^2}\Lambda^{2n\mu_z}@@` 收敛（`@@M@@n\ge4\Lambda\mu_z@@` 时 `@@M@@\Lambda^{2n\mu_z}\le2^{n^2/2}@@`），故一切混合导数属于 `@@M@@L^\infty\cap L^2@@`。力由 `@@M@@f=\partial_tU+(U\cdot\nabla)U-\nu\Delta U@@` 直接给出；速度公式同时列出所有分支、不引用实际选中的分支序列，配合 `@@M@@e^{-1/t}@@` 型光滑断面（profile）的有效导数界与周期化的有限平移集，实现"不先运行机器再回放"的有效求值；无散度版本由有效的傅里叶投影引理给出。唯一性仍用差能量比较加 Gronwall 不等式。

## 深入探讨：像审稿人一样追问 🔍

**问 1：证明中最关键、最脆弱的一步是什么？**

（答：第 5 节的导数交换不等式 ‖∂ₜ^h∂_X^μ U‖∞ ≤ C Sₙ^{−1−h}Λ^{nμ_z} 加上级数 Σ 2^{−(1+2h)n²}Λ^{2nμ_z} 的收敛（n≥4Λμ_z 时 Λ^{2nμ_z}≤2^{n²/2}）。门函数对 z 求一次导付出 Λⁿ，步长 Sₙ=2^{n²} 必须同时压住所有阶；这个指数账算错一位，"一切混合导数 L∞∩L²"即告失效，而它是本文区别于姊妹篇的卖点。）

**问 2：为什么必须有第三坐标的历史记录，不能只靠平面编码？**

（答：机器指令可以覆盖符号、合并状态，而光滑流在两时刻之间的映射可逆。本文不改机器（不像可逆记录器姊妹篇），而是让每个已选分支编号以 Λ 进制逐位留在 z 里：旧数位化作整数部分、不再影响门，却未消失，于是平面像重叠的不同分支仍代表不同过去。这是 Bennett 历史带的连续版。）

**问 3：与已有流体计算工作相比真正的新意是什么？**

（答：CMPP 的欧拉流要黎曼三球面与非零初速，DGMP 要改编度量并靠 Hodge 粘性让黏性项消失，CMP 的有界模拟也在非零 Beltrami 初速上截段。本文在固定平坦环面、固定正可计算粘度、零初速下把机器全部写进外力，并首次让力与速度的一切混合导数同时 L∞ 且时间 L²——正则性标准是族内最强的；"最终定常外力"问题则明确交给引用的姊妹篇 [Stationary]。）

**问 4：无散度版本会不会改变物理结论？**

（答：不会。原文外力经引理的傅里叶投影 f−∇φ 改为无散度，速度 U 不变、压强变为 −φ，粒子事件与导数界都原样保留。这也说明"零压强"并非本篇的约束——它不同于剪切流姊妹篇里对流项恒零的构造。）

**问 5：这个结果最可能以什么方式出错？**

（答：AI 生成证明的典型风险藏在小数与门的组合细节：门宽 1/(4Λ) 是否在所有 Λⁿ 缩放下仍不串门、z 在环面上的绕回（论文专门论证 0≤zₙ≤1−Λ⁻ⁿ 无绕回歧义）、以及"不求实际分支序列、对所有分支一并写出公式"的有效求值程序中避免对实参取整。任何一处缝隙都可能让门选错指令，等价性悄无声息地失效。且本文未形式化。）

**问 6：下游推论与适用边界在哪里？**

（答：推论是固定粒子事件对该编译器产出力类的不可判定性（与停机判定、图灵符号打印问题复合即得）。用家是可计算性分析与流体可计算性方向。但适用边界要讲清：结论针对精确实数坐标上的轨线，论文明示不给任意长运行的一致扰动容限，也无高效模拟界——第 n 步耗时 2^{n²}，物理实现性极弱。）

**总评**

这是族内正则性最强的"普通机器直接进流体"构造，历史坐标换步长的时间交换干净漂亮；最大风险在门函数尺度与进制记账的组合细节未形式化，以及结论离物理可实现尚有精确坐标这道鸿沟。
